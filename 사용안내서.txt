====================================
  팀 주간 일정 & 결재 관리 사용 안내
====================================

[시작하기]
1. Google Drive 공유 폴더에서 파일을 모두 다운로드하세요.
   - 폴더 우클릭 → "다운로드" 하면 ZIP으로 받을 수 있습니다.
2. 압축을 풀고 "member.html"을 더블클릭하면 브라우저에서 열립니다.

※ Google Drive 미리보기로는 동작하지 않습니다.
   반드시 다운로드 후 사용하세요!

------------------------------------

[팀원 사용법]

 1) member.html 열기
 2) 이름, 직책 입력 → "시작하기" 클릭

 <주간 일정 입력>
 - "주간 일정" 탭 선택
 - 각 요일에서 업무 / AS / 휴가 선택
 - 내용 입력 후 "+" 버튼 클릭
 - 이전/다음 주 이동 가능

 <결재 계획 등록>
 - "결재 계획" 탭 선택
 - 협력업체명, 결재 내용, 금액(원) 입력
 - "추가" 버튼 클릭

 <데이터 제출>
 - 입력 완료 후 상단 "내 데이터 내보내기" 클릭
 - JSON 파일이 다운로드됩니다
 - 이 파일을 Google Drive "제출" 폴더에 업로드

------------------------------------

[관리자 사용법]

 1) dashboard.html 열기

 <팀원 데이터 가져오기>
 - 상단 "팀원 데이터 가져오기" 클릭
 - 팀원들이 올린 JSON 파일을 선택 또는 드래그&드롭
 - 여러 명 파일을 한번에 불러올 수 있습니다

 <주간 일정 확인>
 - "주간 일정" 탭에서 전체 팀원 일정 확인
 - 업무/AS/휴가 필터로 원하는 항목만 보기
 - 이전/다음 주 이동 가능

 <결재 현황 확인>
 - "결재 현황" 탭 선택
 - 총 결재 건수, 협력업체 수, 총 결재 금액 요약
 - 팀원별 결재 목록 + 소계
 - 협력업체별 금액 집계 + 비중(%) 확인

 <데이터 백업>
 - "전체 저장" → 전체 데이터를 JSON으로 백업
 - "전체 불러오기" → 백업 파일에서 복원

------------------------------------

[매주 반복 순서]
 1. 팀원: 매주 월요일 일정 입력 + 결재 등록
 2. 팀원: "내 데이터 내보내기" → Drive에 업로드
 3. 관리자: JSON 파일 가져오기 → 대시보드 확인

------------------------------------

[파일 설명]
 - index.html      메인 화면 (팀원/관리자 선택)
 - member.html     팀원 일정 & 결재 입력
 - dashboard.html  관리자 통합 대시보드
